# 사연별 위로 추천 검토 (2026-09-15)

## 확인한 문제

- 기존 300개는 15개 기본 글에 19개 공통 변형을 붙인 구조여서, 다루는 상황은 15개였다.
- `욕`, `늦`, `계속`, `연락` 등 부분 문자열이 실제 사건과 무관하게 점수를 얻었다. 전화·문자 언급은 충동 감정으로 취급됐다.
- 사연에 단서가 없어도 카테고리·스타일 점수와 ID 정렬 순서로 특정 사건을 단정했다.
- 이야기군을 고른 뒤 입력 해시로 공통 행동 문구를 선택해, 원래 상황과 맞지 않는 행동을 권할 수 있었다.

## 변경

- 25개 상황별 본문과 1개 공통 위로를 직접 작성했다. 총 326개 ID를 유지하며, 추천 대상은 40개 상황의 기본 글과 공통 위로 1개다. 기존 변형 ID는 삭제하지 않았다.
- 이별, 사별, 반려동물 상실, 돈 걱정, 실직, 과로, 직장 내 상처, 공로 가로채기, 괴롭힘, 간병, 육아, 가족 기대, 부부 갈등, 답장 기다림, 배신, 건강 걱정, 수면 어려움, 학업, 취업 준비, 업무 실수, 받지 못한 사과, 외모 평가, 새 환경 적응, 계획 취소, 이동 스트레스를 구분한다.
- 구체적인 사건을 일반 감정보다 우선한다. 필요한 경우 사람·장소 등 맥락 단서도 함께 요구한다.
- 카테고리와 스타일은 동일 우선순위의 동점에만 사용한다. 기분 선택기의 강도는 사건 판단에 사용하지 않는다.
- 명시적 부정과 일부 미래 가정 표현을 제외한다. 띄어쓰기 유무는 같은 결과를 낸다.
- 근거가 없으면 `general_support`를 반환한다. 공통 변형 문구는 새 추천에 사용하지 않는다.

## 검증 범위

- 84개 작성 사연으로 기대 상황을 확인했다. 각 사연을 공백 제거, 4개 스타일, `많이 화남` 선택 상태에서도 검증했다.
- 추가 검증: 카테고리만으로 사건을 만들지 않는지, 모델 호환성, ID·본문 고유성, 본문 100자 제한.
- `flutter test --no-pub`: 전체 169개 통과.
- `flutter analyze --no-pub`: 문제 없음.
- 실제 이용자 사연을 수집하거나 외부 서비스로 전송하지 않았다. 위 수치는 작성한 회귀 사례의 결과이며 운영 환경의 추천 정확도 수치가 아니다.

## 한계와 운영 반영

규칙 기반 분류이므로 간접 표현, 인용, 복잡한 부정, 여러 사건의 우선순위는 오분류될 수 있다. 미인식 표현은 공통 위로로 연결된다. 같은 상황에는 같은 기본 본문이 제공되므로 문구 다양성보다 관련성을 우선한다.

변경은 앱에 포함된 로컬 코드와 콘텐츠다. 기존에 저장된 위로글은 다시 선택하지 않으며, 설치된 앱에 반영하려면 새 앱 버전 빌드와 배포가 필요하다.
