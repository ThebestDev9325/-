참을인은 사용자가 감정을 기록하고 돌아보는 앱입니다. 앱 하단의 작은 배너를 통해 콘텐츠, 서비스, 브랜드를 자연스럽게 알릴 수 있습니다.

광고 노출 위치와 방식

위치앱의 주요 화면 하단, 네비게이션 바 바로 위에 노출됩니다.
구성한 번에 2개의 배너가 화면 너비를 반씩 나누어 표시됩니다.
순환총 4개 슬롯이 2개씩 묶여 10초 간격으로 교대됩니다.
연결배너를 누르면 신청한 HTTPS 웹페이지 또는 채널이 열립니다.

제작 규격

이미지 비율가로형 2:1 권장 (예: 1200×600px 또는 1024×500px)
파일JPG, PNG 또는 WebP / HTTPS로 접근 가능한 이미지 URL
문구배너 안에 표시할 짧은 이름 또는 제목 1개
연결 주소HTTPS 방식의 랜딩 페이지, 쇼핑몰, SNS 또는 YouTube 채널
가독성작은 배너에서도 알아볼 수 있도록 핵심 문구와 로고를 중앙에 크게 배치해 주세요.

실제 화면에서 이미지 위에 밝은 오버레이와 광고 표시가 적용됩니다. 작은 글씨나 가장자리의 중요한 요소는 잘릴 수 있어 피하는 것이 좋습니다.

게재 절차

  1. 이메일로 브랜드·서비스 소개와 희망 기간을 보내주세요.
  2. 제작한 이미지, 표시 문구, 연결 주소를 함께 전달해 주세요.
  3. 콘텐츠와 링크를 확인한 뒤 게재 일정과 조건을 개별 안내합니다.
  4. 확정된 일정에 원격으로 게재하며, 앱 업데이트 없이도 광고 교체가 가능합니다.

게재할 수 없는 내용

불법·사기, 성인·사행성, 혐오·차별, 폭력, 과장 또는 사용자에게 해를 줄 수 있는 내용은 게재하지 않습니다. 참을인의 성격과 이용자 보호 기준에 따라 게재가 제한될 수 있습니다.
