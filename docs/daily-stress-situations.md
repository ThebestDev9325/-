## 층간소음 예시

사연: “층간소음 때문에 스트레스를 너무많이 받아”

제목: **집에서도 편히 쉴 수 없을 때**

> 집에서는 좀 편히 쉬고 싶은데 소음 때문에 그러지 못하면 정말 지치겠어요. 내가 원할 때 멈출 수도 없는 소리를 견디는 건, 소리 자체뿐 아니라 내 휴식이 방해받는 일이기도 하니까요. 또 소리가 날까 신경 쓰다 보면 쉬어도 쉰 것 같지 않을 수 있어요. 집에서만큼은 조용히 쉬고 싶다는 마음은 무리한 바람이 아니에요.

마무리: “누군가에게는 잠깐의 소리여도, 계속 듣는 당신에게는 긴 피로일 수 있어요.”

잠을 못 잤다는 단서가 함께 있으면 **소음 때문에 잠까지 빼앗긴 밤**을 우선한다. 사연을 입력할 때 고른 카테고리만으로 이 내용을 바꾸지 않는다.

## 구현과 검증 범위

- `flutter analyze --no-pub`: 문제 없음.
- `flutter test --no-pub`: 전체 272개 통과.

- 신규 24개 본문과 추천 단서를 한 데이터 구조에 넣어, 글을 추가하고 추천 연결을 빠뜨리지 않도록 했다.
- 전체 콘텐츠 358 → 382개. 서로 다른 추천 상황 72 → 96개와 공통 위로 1개. 기존 변형 글 ID는 유지한다.
- 신규 본문은 120~400자 범위, 전체 DB의 ID와 본문 고유성을 검증한다.
- 새 24개 상황을 모두 포함하는 34개 사연을 4개 스타일·띄어쓰기·기분 변형으로 검증한다.
- 부정·해결·긍정·인접 상황 20개를 별도로 검증한다. 실제 사용자 만족도나 운영 추천 정확도 수치가 아니다.
- 기존 긴 위로글 화면 테스트와 추천 회귀 사례를 함께 실행한다.

규칙 기반이므로 간접 표현, 인용, 복잡한 부정과 복합 사연은 오분류될 수 있다. 앱에 포함된 DB이므로 설치된 앱에는 새 버전 배포 후 반영된다.
