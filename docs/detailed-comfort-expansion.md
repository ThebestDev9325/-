# 구체적인 사연을 알아주는 위로글 보강

## 작성 기준

기존 ‘과로’ 위로는 사용자가 말한 늦은 야근, 새벽 재출근, 거절하기 어려운 사정과 부족한 휴식을 충분히 짚지 못했다. 사용자가 더 와닿는다고 평가한 새 문장을 DB에 넣고, 같은 작성 방식으로 여러 생활 상황을 보강했다.

각 글은 실제 상황을 먼저 짚고, 그 안에서 생길 수 있는 서러움·허탈함·눈치·기다림을 알아준다. 당장 해결하거나 다시 힘내도록 재촉하지 않는다. 사연에서 알 수 없는 상대의 의도를 단정하지 않는다.

## 추가한 32개 글

- 직장 10개: 야근 뒤 새벽 재출근, 아픈데 출근, 퇴근 후 업무 연락, 휴가 눈치, 업무 떠넘기기, 공개적인 질책, 반복해서 바뀌는 지시, 인정받지 못한 수고, 신입의 질문 부담, 잘못 없이 고객에게 사과.
- 가족 6개: 독박 육아, 아이에게 소리친 뒤 후회, 간병 중 쉬고 싶은 죄책감, 혼자 맡는 집안일, 가족의 비교, 결혼 재촉.
- 관계·상실 8개: 가볍게 넘겨진 고민, 늘 먼저 하는 연락, 갑작스러운 약속 취소, 나만 빠진 모임, 반복된 약속 위반, 이별 뒤 연락하고 싶은 습관, 기일의 그리움, 외로운 생일.
- 진로·학업 3개: 반복 불합격, 공부한 만큼 나오지 않은 점수, 주변 취업 소식과 비교.
- 생활 3개: 월급 후 남는 돈 없음, 밀린 월급, 예상하지 못한 지출.
- 건강 2개: 검사 결과 기다림, 겉으로 보이지 않는 통증.

총 콘텐츠는 326개에서 358개로 늘었다. 기본 추천 상황은 40개에서 72개로 늘었으며 별도의 공통 위로가 있다. 기존 글 ID는 유지했다.

## 추천과 화면

- 새 글마다 구체적인 상황 단서 조합을 연결했다. 예를 들어 야근과 새벽 출근이 함께 있을 때 재출근 글을 선택한다. 야근만 있으면 기존 과로 글을 유지한다.
- ‘새벽 출근은 안 해’라는 명시적 부정은 재출근 글에서 제외한다.
- 새 긴 글은 100자에 자르지 않는다. 기존 글은 기존 길이 검증을 유지하고 새 32개만 400자 이내로 검증한다. 본문은 기존 스크롤 화면에서 모두 표시된다.
- 작은 화면(360×640), 글자 배율 1.3에서 실제 글쓰기 흐름을 거쳐 전체 본문과 피드백 버튼 접근을 확인하는 위젯 테스트를 추가했다.

## 검증 범위와 적용

- `flutter analyze --no-pub`: 문제 없음.
- `flutter test --no-pub`: 전체 216개 통과.

새 32개 ID를 모두 포함하는 33개 긍정 사례, 과잉 매칭을 막는 12개 사례, 기존 84개 회귀 사례를 사용한다. 새 긍정 사례는 띄어쓰기 제거·4개 스타일·기분 선택 변형에서도 확인한다. 기존의 넓은 분류 중 더 구체적인 글이 추가된 사례는 기대 결과를 새 글로 갱신했다.

규칙 기반 DB 추천이므로 임의의 사연에 대해 매번 새 위로글을 생성하지는 않는다. 새로운 간접 표현이나 복합 상황에는 오분류가 남을 수 있다. 이 사례 검증은 실제 사용자 만족도 측정과 다르다. 앱에 내장된 데이터이므로 새 버전 배포 후 설치된 앱에 적용된다.
